# Dữ liệu mẫu

Theo đề tài, dữ liệu mẫu tối thiểu gồm:

- 03 khu vực.
- 05 loại rác.
- 03 điểm tập kết.
- 05 nhân viên.
- 10 người dân.
- Tài khoản Admin, Nhân viên và Người dân tương ứng.
- 15–20 yêu cầu thu gom, chi tiết, phân công và kết quả.

Dữ liệu cần đủ các trạng thái để kiểm tra CRUD, Validation, tìm kiếm, lọc, phân quyền, nghiệp vụ và thống kê.
