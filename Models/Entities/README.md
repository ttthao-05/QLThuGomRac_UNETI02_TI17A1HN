# Entity

Các Entity tối thiểu theo đề tài:

- `TaiKhoan`
- `KhuVuc`
- `LoaiRac`
- `DiemTapKet`
- `NguoiDan`
- `NhanVien`
- `YeuCauThuGom`
- `ChiTietYeuCau`
- `PhanCongThuGom`
- `KetQuaThuGom`

Mỗi Entity cần xác định Primary Key, Foreign Key, Navigation Property, kiểu dữ liệu, Validation và ràng buộc nghiệp vụ trước khi tạo Migration.
