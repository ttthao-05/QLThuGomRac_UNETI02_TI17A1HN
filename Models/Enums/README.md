# Enum

Các nhóm trạng thái cần định nghĩa:

- Loại tài khoản: Admin, Nhân viên, Người dân.
- Trạng thái tài khoản: Đang hoạt động, Đã khóa.
- Trạng thái nhân viên: Đang hoạt động, Tạm nghỉ.
- Trạng thái yêu cầu: Chờ xác nhận, Đã xác nhận, Đã phân công, Đang thu gom, Hoàn thành, Từ chối, Hủy.
- Trạng thái phân công và kết quả thu gom.
