# ViewModel

Các ViewModel sẽ được tổ chức theo chức năng:

- `Account/`: đăng nhập, đăng xuất, đổi mật khẩu.
- `Module1/`: tài khoản, khu vực, loại rác, điểm tập kết.
- `Module2/`: hồ sơ người dân, đăng ký lịch, tra cứu yêu cầu.
- `Module3/`: phân công, xử lý yêu cầu, nhập kết quả thu gom.
- `Module4/`: dashboard, báo cáo và thống kê.

ViewModel dùng cho Model Binding, Data Annotation và hiển thị thông báo lỗi trên View.
